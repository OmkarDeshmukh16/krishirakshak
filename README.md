# 🌾 KrishiRakshak (कृषीरक्षक)
### Smart Agricultural Health Platform — Early Detection & Management of Crop Diseases & Pest Infestations
> **SIH Problem Statement 26131**: *Early Detection and Management of Crop Diseases and Pest Infestations*

---

## 🌟 Overview
**KrishiRakshak** is a modern, responsive digital crop-health platform designed to empower farmers, agricultural scientists, and district agriculture officers with proactive crop protection capabilities. By combining simulated AI-driven leaf pathology diagnostics, meteorological risk modeling, interactive GIS disease hotspot surveillance, and multi-channel advisory dissemination, KrishiRakshak bridges the gap between field-level crop stress and rapid agricultural intervention.

---

## 🚀 Key Modules & Capabilities

### 👨‍🌾 1. Kisan / Farmer Portal
- **Smart Farm & Crop Ledger**: Real-time crop health indices, phenological stages, NPK status, and irrigation schedules.
- **AI Crop Health Assessment**: Instant simulated optical diagnostics with confidence scores, contributing environmental triggers, and immediate cultural measures.
- **7-Day Predictive Risk Forecast**: Multi-parameter threat projection (Fungal Disease, Insect Pest, Rainfall/Humidity exposure) with interactive Recharts area curves.
- **Localized Weather Intelligence**: Current conditions, dew point, rainfall metrics, and disease-weather susceptibility matrices.
- **Certified Agricultural Advisories**: Symptom checklists, organic biological controls, and chemical intervention standards.
- **Direct Expert Tele-Consultation**: Ticketed case tracking with ground photos, field history, and verified scientist responses.
- **Interactive AI Assistant (Kisan Bot)**: Agricultural chatbot answering queries on pest management, soil biology, and government schemes.
- **Farmer Community Forum**: Peer experience sharing with disclaimers, discussions, and photo documentation.

### 🔬 2. Agri-Expert / Scientist Portal
- **Case Review Workstation**: Clinical case queue categorized by urgency and pathogen severity.
- **Diagnostic Validation**: Side-by-side review of farmer observations, AI pre-diagnostics, weather history, and high-resolution crop photos.
- **Prescription & Treatment Authoring**: Formal pathological certification and spray dose formulation dispatch.

### 🏛️ 3. Agriculture Officer / Command Center
- **Regional Surveillance Dashboard**: Division-level statistics covering registered acreage, containment ratios, and threat distributions.
- **Interactive GIS Disease Hotspot Map**: Geospatial cluster visualization powered by Leaflet with real-time severity markers, spread trajectories, and quarantine protocols.
- **Epidemiological Trend Analytics**: Longitudinal outbreak tracking, dominant pathogen breakdowns, and seasonal vulnerability forecasting.
- **Emergency Advisory Broadcaster**: Targeted multi-channel dissemination (SMS, WhatsApp Kisan Bot, App Push) filtered by district, crop, and severity.

## 🛠️ Technology Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 with custom agricultural design system
- **Icons**: Lucide React
- **Charts & Data Visualization**: Recharts
- **Geospatial Mapping**: Leaflet & React-Leaflet
- **Routing**: React Router DOM v7
- **State & Storage**: React Context + Browser LocalStorage persistence

## ⚡ Getting Started

```bash
# Clone the repository
git clone https://github.com/OmkarDeshmukh16/krishirakshak.git

# Navigate to project directory
cd krishirakshak

# Install dependencies
npm install

# Start Vite development server
npm run dev
```
